# 风堇Ark自动助手

右上角下拉框提供“主站修仙”和“避难所”两个模式，统一使用浅色紫色面板。主站修仙保留奇遇循环、定时远征、迷雾探索与核心过载；避难所提供居民配对、居民信息、一键安排和一键托管四个独立页签。打开时根据当前页面选择对应模式与功能，也可手动切换。

## 安装

1. 停止旧扩展中的运行任务，并在 Chrome 扩展管理页面禁用原来的四个扩展，避免重复操作。
2. 刷新游戏页面，清除旧扩展已注入的脚本。核心过载若仍有进行中的战斗，请先手动处理完成。
3. 打开 chrome://extensions，开启开发者模式，选择“加载已解压的扩展程序”，选择本文件夹。
4. 在对应游戏页面打开扩展，设置参数后点击开始。

## 功能

以下四项位于“主站修仙”模式。

- 奇遇循环：修炼页面；保留检查间隔、最多检查次数与每轮结束等待设置。
- 定时远征：远征页面；保留今日突发额度选项与领取倒计时。每轮最晚完整到达时间 + 1 分钟后自动刷新一次，刷新后继续领取并进入下一轮；领取仍按每 5 秒检查、最多 20 次执行。
- 迷雾探索：迷雾页面；保留固定路线与战斗策略。
- 核心过载：从关卡选择页启动；常用栏前三位必须为石墙卫、光环辅助、雷电法师。保持游戏标签页在前台，勿同时手动布置。

## 避难所

在自己的 `https://game.arkengine.me/shelter` 页面使用，功能迁自 ark-ch 版本，保留原有策略。

- 居民配对：按七项基础属性总和推荐非亲子、无共同父母的组合，排除儿童、在宿舍培养感情和家庭冷却中的居民；有感情记录但不在宿舍的居民可以参与配对；支持高分配对优先安排高级宿舍，每间一对成人。
- 居民信息：属性、战力排序，感情及家庭冷却进度，出生与成年倒计时，以及按“最高基础属性-编号”一键改名；名称中带有 ★ 的居民保留原名，不修改编号或亲本标记。其他居民已有编号及其他大写后缀保留，无编号者从现有最大编号后接续；A/B/C/D 每次重新分配给全部居民（含儿童）中七项基础属性总和合计最高、两对不重复用人的组合，A＋B、C＋D 分别配对；仅各对内排除亲子及共同父母，跨对允许亲属关系。高总分的一对标记 A、B，另一对标记 C、D，各对内高分者在前，同分按 ID 排序，凑不足两对时不标记。
- 一键安排：提供“一键安排居民”和“一键整理房间”两个按钮。居民安排按六项最高基础属性（不含幸运）分配，唯一最高者先安排，并列最高者补位或替换低值居民；同类优先高等级、大容量房间。智力先零件工坊后医务室，魅力安排电台。剩余居民去最高属性训练室，最高属性已满 10 则选择其他未满属性的可用训练室（包含幸运）；无合适训练空位时补生产空位，资源缺口优先、基础属性匹配其次，导致废料亏损的工坊最后补，生产房全满才移到门外。原训练室居民及非家庭冷却中的宿舍居民保留。完成后显示预计资源收支（废料扣除工坊消耗），亏损仅提示手动调整，不自动改派。
- 一键整理房间：先检查全局施工、升级、事件和制作，再规划全部步骤。由上至下排列发电站、餐厅、净水站、医务室、零件工坊、废料回收站、训练室、电台、武器工坊、服装工坊、宿舍、仓库。同类尽量同层，同等级相邻；训练室按属性分组，宿舍尽量靠底，仓库放最下层。先将大房间拆成单格，利用至少 1 格现有空位中转；移动中意外合并的房间重新拆成单格，到位后恢复自动合并。不升级、不额外调动居民；无空位时不执行。逐步核对返回结构与居民位置，结果不符立即停止，不回滚已完成操作。恢复自动合并后最多合为 3 格。
- 一键托管：默认每 300 秒按刷新数据、全部收取、事件处理、新人改名、造神计划、废土检查顺序执行。事件救援和新人遣散均为勾选后可展开的设置组，组内条件使用单选。事件救援默认关闭，救援方式默认选择专人专救，也可切换为一键救援（默认 3 次）。专人专救：变异鼠、掠夺者、深层野兽从发电站和武器工坊调人，灭火、堵漏从餐厅调人；只调用无事件房间中在家存活的成人，按事件房间空位派入。无事件无快照时直接继续；有事件无快照时保存站位并按所选方式救援；有事件有快照时保留快照、继续后续步骤；无事件有快照时恢复在家存活成人的站位，恢复完成后清除快照。关闭事件救援时暂停救援和归位，已有快照保留到再次启用。新人改名后保持门外，不自动安排房间。新人遣散默认关闭，默认选择指定属性，耐力低于 4 则遣散；启用后可单选总属性（默认 20）或指定单项基础属性（阈值 1–10），单项可从力量、感知、耐力、魅力、智力、敏捷、幸运中选择；严格低于所选阈值才遣散，仅处理本次开启后新出现的电台门外成人，已有居民不遣散。废土默认触发 6 次事件后召回（不含出发日志），到家领取后先检查血量，低于 60% 时使用一次治疗针，再按原区域、治疗针数量和深渊设置再次派出；无探险时跳过。页面提供只读日志，保留最近 2000 条。托管默认关闭，运行期间禁止其他居民调动与改名任务；关闭面板后继续，刷新或关闭游戏页面后停止并清除内存状态。

造神计划位于一键托管中，默认不勾选，勾选后展开亲本训练列表；点击标题也可勾选。只处理训练室内在家存活的成人，使用基础属性判断满 10。名称含 ★ 的造神亲本练满当前属性后，按其余未满属性从高到低寻找有空位的训练室，不存在或满员就继续查找，都没有则去休息。普通居民练满后，遍历所有对应生产房间，从全部在岗员工中选择该属性低于 10 的最高者交换，先去休息腾位；力量对应发电站、感知对应净水站、敏捷对应餐厅、智力对应工坊和医务室、耐力对应废料回收站、魅力对应电台，幸运无对应岗位。没有可交换员工或幸运练满时去休息。列表在勾选或重新打开运行中的面板时读取一次，之后随每轮托管检查更新亲本当前训练属性、本级进度和按当前空位预估的下一站；居民调动按托管检查间隔执行。存在事件或救援站位快照时暂停造神调动，归位完成后继续。

房间整理规划完成后，先显示预计楼层分配、拆分/移动/恢复合并次数与房间数量变化，再提供“确认执行”和“取消整理”。确认前不提交任何房间操作；关闭面板保持等待，重开后仍可确认或取消。确认时重新检查房间状态和布局，变化后停止并要求重新规划。

避难所任务开始执行后关闭面板仍会继续，刷新或关闭游戏页面会中断；执行失败即停止，已完成的调动或改名保留。配对宿舍和生产安排不能同时执行。

切换功能或关闭面板不会停止已启动的任务。请在对应页面与功能面板中点击停止。原有页面操作和停止条件保持不变；核心过载保留跨页面状态与自动注入机制，远征仅在上述自动刷新后恢复领取，手动刷新仍结束任务；其余任务在刷新或关闭游戏页面后结束。
